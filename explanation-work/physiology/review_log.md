# Cardiovascular physiology review

Source order uses the three sets in data/past-questions.json. Progress and per-file blob identities are in progress.json. Draft explanations are overlaid on the pinned source in memory for the supplied audit. Each changed or accepted question was read with its original stem, labels, key and existing explanations. Holds are excluded from draft application. Full-file random spot checks are pending file completion.

The workspace handoff contained no lecture PDFs. These are textbook-level reviews. No claim is made to have verified a local course convention or consulted the full Guyton & Hall textbook. Public excerpts of Ganong’s examination companion and open supplementary sources were used.
